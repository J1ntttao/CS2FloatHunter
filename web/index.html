CS2 磨损猎人

粘贴配方链接确定收藏品 → 输入你想要的产物磨损 → 自动搜出能打出这个磨损的 10 把皮肤
仅 BUFF：唯一能拿到逐笔精确磨损的来源，用来精确求解。
BUFF + Steam：以 BUFF 求解，同时查 Steam 最低价做比价，标出哪边更便宜。
仅 Steam：Steam 拿不到逐笔磨损（其挂单 float 只在游戏内检视数据里）， 只能给「该商品该磨损档的最低价」，无法保证命中你指定的精确磨损，仅作价格参考。
Steam 部分需要能访问 steamcommunity.com；本机若有 SteamTools 等中间人， 已默认放宽证书校验（可用下方开关关闭）。
④ 登录态设置（BUFF Cookie / Steam Cookie）— 点开填写
F12 → Network → 刷新 → 点任意请求 → Request Headers 里的 Cookie: 整行。
必需：BUFF 的搜索接口必须登录才能用。
Steam 登录态由 steamLoginSecure 承载（值形如 <steamid64>%7C%7C<token>）。 F12 → Application → Cookies → steamcommunity.com → 复制 steamLoginSecure 的 Value。
逐笔磨损靠本地解码检视链接得到，不需要 CSFloat 服务； 但要能打开 Steam 挂单页（本机被 SteamTools 拦，需代理）。
实测 api.csfloat.com 已无法解析域名（官方 2026-03 起废弃）， 所以这栏基本用不上，留着以防官方恢复。留空即可。
链接形如 https://cs2up.cn/share.html?sid=<16位id>，也可以只贴 sid 本身。
链接只用来定位「哪个收藏品、哪一档材料」（例如「创世纪收藏品 · 受限级」）； 目标磨损由你决定，不必和链接里那个配方一样。
磨损搜索半径：在算出的材料目标磨损上下各搜多大范围。调大更容易凑齐，但抓取更慢。
原理：同一收藏品内所有皮肤的磨损区间相同，所以「想要的产物磨损」就等于「材料的平均磨损」。
计算引擎：西林磨损计算器（68688888.github.io）的官方算法，已与其源码逐位对齐。
收藏品/材料清单来自配方链接 + 本地材料库；挂单与精确磨损来自 BUFF163。挂单随时可能被买走，请尽快下单。
