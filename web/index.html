CS2 磨损猎人

贴配方链接定收藏品，填目标产物磨损，自动搜出能打出这个磨损的 10 把材料。

搜索条件

保留链接中每个收藏品的投入数量，允许替换为同收藏品、同等级的其它枪皮；材料磨损根据你输入的目标产物磨损重新计算。也可只贴 sid。
读取链接后自动跟随配方品质，可手动切换。
目标磨损会按所选产物的完整区间计算。
每把武器的每个品质档独立抽页，默认 20 页；填 0 则顺序抓取。首页用于确认总页数，计入抽页数量。
搜索品质等级（外观磨损，可多选）
按勾选档位搜索每把枪皮的完整 float 区间，并取该枪皮自身上下限的交集；逐页保留真实挂单并拟合，高低磨损可互相补偿。未完成的档位可继续搜索。
BUFF 提供逐笔精确磨损，用于精确求解。
代理与登录态
登录 buff.163.com，按 F12 → Network → 该站点的请求 → Request Headers，复制完整 Cookie 值，必须包含 session；支持 Cookie: 前缀和 Cookie-Editor JSON。仅 Steam 模式可留空。
登录 steamcommunity.com，按 F12 → Application → Cookies → steamcommunity.com，复制 steamLoginSecure 的 Value。格式为 17 位 SteamID + || + 三段 JWT；只填写值，不要带 steamLoginSecure= 或其他 Cookie 字段。
